## 지금 있는 것 (바꾸기 전에 꼭 읽기)

류소 옷장 앱(React 19 + TS + Vite + Tailwind v4 PWA, 저장소 `somethingrsy-rgb/ryusocloset`)의 보물 탭 **축구** 게임을 업그레이드해 줘.

- 화면: `src/components/SoccerGame.tsx`. 움직임·규칙: `src/lib/soccer.ts`(순수 함수 `newMatch`·`stepMatch`). 테스트: `src/lib/soccer.test.ts`
- 경기장 100×60 단위. 빨강 팀(0)은 왼쪽(세로 화면은 아래) 골대를 지키고, 보라 팀(1)은 반대쪽
- 팀마다 아바타 1명과 동물 4마리(골키퍼 1, 필드 3). 동물 그림 `public/cafe/stand/<동물>_stand.webp`·`_wave.webp`, 얼굴 `public/cafe/face`
- 아바타는 경기 중 항상 축구복+축구화(빨강 `costume_soccer_red`·`shoes_soccer_red`, 보라 `..._purple`), `KitFigure` 가 그 아바타의 몸·머리로 그림
- 혼자 하기(보라 팀 아바타는 컴퓨터) / 둘이 하기(한 화면에서 한 팀씩, 화면 반쪽씩 터치). 손가락을 따라 달리고 공에 닿으면 저절로 참
- 혼자 하기는 `cpuStrength` 로 점수 차에 따라 컴퓨터 팀 힘을 바꿔 아이가 10판에 7판쯤 이기게 맞춰 둠(테스트로 확인). 비기면 골든골 45초
- 2분 경기, 골 소리 `playWin`, 찰 때 `playHop`, 배경 음악 `startBgm('run')`

## 지켜야 할 것

- 6~9살 아이용: 실패해도 속상하지 않게, 큰 버튼, 글 적게, 그림 위주
- 혼자 하기 이길 확률 7:3 은 유지(바꾸는 기능마다 `soccer.test.ts` 의 확률 테스트가 계속 통과해야 함. 필요하면 `cpuStrength` 숫자를 다시 맞추기)
- 선수끼리 몸이 겹치지 않게 하는 것, 골대 옆 팀 이름, 골키퍼 표시는 그대로
- 앱 전체의 `button { font: inherit }` 때문에 버튼 글자 크기·굵기는 style 이나 안쪽 span 에
- 세로(폰)·가로(폰 가로·패드) 모두 확인

## 업그레이드 목록

### 1단계: 손맛 (가장 먼저)
1. **슛 버튼(선택)**: 아바타가 공 가까이 있을 때 화면 구석에 큰 ⚽ 슛 버튼. 누르면 더 세게, 손가락으로 끈 방향으로 참. 기존 "닿으면 저절로 차기"는 그대로 둬서 버튼 없이도 할 수 있게
2. **패스**: 공을 가진 내 아바타가 같은 팀 동물 쪽으로 손가락을 끌면 그 친구에게 패스. 동물이 받으면 잠깐 공을 몰고 감
3. **공 모는 느낌**: 공이 발 앞에 붙어서 같이 굴러가다가(드리블), 방향을 크게 바꾸거나 상대가 닿으면 떨어지게
4. **골 연출**: 골이 들어가면 그물 흔들림, 넣은 팀 동물들이 손 흔드는 그림(`_wave.webp`)으로 바뀌고 폴짝 뜀, 짧은 꽃가루. 1.6초 뒤 다시 시작
5. **소리**: 휘슬(시작·끝·골), 관중 환호, 찰 때 공 소리. 효과음 끄기 설정을 따르기

### 2단계: 경기 모드
6. **경기 시간 고르기**: 1분 / 2분 / 3분
7. **난이도(혼자 하기)**: 쉬움(8:2) / 보통(7:3, 기본) / 어려움(5:5). `cpuStrength` 를 난이도별 표로 바꾸고, 난이도마다 확률 테스트
8. **페널티킥 놀이**: 경기 대신 5번씩 번갈아 차기. 차는 쪽은 방향을 누르고, 막는 쪽(골키퍼 동물)은 컴퓨터가 막거나 둘이 하기면 상대가 방향을 누름
9. **골든골** 은 혼자 하기에만 있는데, 둘이 하기에도 켤지 시작 창에서 고르게

### 3단계: 꾸미기와 모으기
10. **경기장 고르기**: 잔디 / 바닷가 모래 / 눈밭 / 밤 경기장(조명). 새 배경 그림이 필요하면 아래 "그림 목록"에 적고, 그림이 없으면 지금처럼 CSS 줄무늬로
11. **팀 이름·깃발**: 시작 창에서 팀 이름을 고르기(예: 딸기팀, 별빛팀) — 골대 옆 이름도 그 이름으로
12. **기록**: 이긴 횟수, 가장 많이 넣은 골, 동물 친구별 골 수를 저장(`ryuso.soccer.v1`, 백업에 자동 포함). 결과 창에 "오늘의 MVP" 동물
13. **보상**: 이기면 상점 별 조금(달리기 게임처럼 `earnStars`), 처음 이기면 축구 관련 소품 하나

### 4단계: 그림 (있으면 더 좋음)
14. 동물 친구 **축구복**: 동물 서 있는 그림 위에 팀 색 조끼(빨강·보라)를 덧입히기 — 그림이 생기기 전에는 발밑 팀 색 동그라미로 구별(지금 방식)
15. 골키퍼 동물 장갑 그림(지금은 🧤 이모지), 공 그림(지금은 ⚽ 이모지), 관중석 그림
