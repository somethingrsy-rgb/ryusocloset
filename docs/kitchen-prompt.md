# 주방 게임 만들기 프롬프트 (농장 → 주방 → 카페)

아래 내용을 그대로 Claude Code 에 붙여 넣어 쓰면 된다.

---

## 하고 싶은 것

류소 옷장 앱(React 19 + TS + Vite + Tailwind v4 PWA, 저장소 `somethingrsy-rgb/ryusocloset`)에 **주방 탭**을 새로 만들어,
**농장에서 수확한 재료 → 주방에서 요리 → 카페에서 서빙**으로 이어지는 게임을 만들어 줘.
6~9살 아이가 하는 게임이라 실패·시간 압박 없이, 큰 버튼과 그림 위주로 쉽게.

## 1. 주방 탭

- 위쪽 탭 줄에 `카페` 바로 오른쪽에 `주방` 탭을 추가한다 (`src/App.tsx` 의 `Mode` 에 `'kitchen'`, `modeBtn('kitchen', 'kitchen', '주방')`).
  - 탭 아이콘 `public/assets/tabs2/kitchen.webp` 가 아직 없다. 생길 때까지는 🍳 이모지로 보여 준다(그림을 못 읽으면 이모지로 바뀌게).
  - 농장·카페처럼 아래 패널 없이 화면 전체를 쓰는 탭으로 한다 (`split`, `aside hidden` 조건에 `'kitchen'` 추가).
- 배경 그림(이미 넣어 둠):
  - 세로 화면(폰): `public/kitchen/kitchen_portrait.webp` (941×1672)
  - 가로로 넓은 화면(패드 가로 등): `public/kitchen/kitchen_wide.webp` (1672×941)
  - 고르는 기준·크기 맞추기는 카페(`CafeGame.tsx` 의 `wide`/`pad` ResizeObserver)와 똑같이 한다.
- 그림 속 자리(그림 크기에 대한 %로 세로·가로 그림 따로 잰다. 카페 `SEATS` 처럼 `portrait`/`wide` 좌표):
  - **냉장고(민트색)**: 누르면 *식료품 칸* — 농장에서 가져온 재료와 기본 재료가 보인다
  - **가운데 조리대 + 도마**: 요리하는 곳. 고른 재료가 도마 위에 올라간다
  - **가스레인지 냄비 / 오븐**: 끓이기·굽기 단계
  - **싱크대**: 씻기 단계(과일·채소)
  - **왼쪽 채소 선반**: 농장 재료(당근·딸기·옥수수) 개수 표시
- 지금 고른 아바타(`FigureLayers`, 옷·머리 그대로)가 조리대 뒤에 서 있고, 누르는 곳으로 걸어간다(카페 아바타 걷기 방식 재사용).

## 2. 재료

- **농장 재료**: 지금 `src/lib/farm.ts` 의 `CROPS` (당근 🥕, 딸기 🍓, 옥수수 🌽). 농장 `inventory` 에서 꺼내 쓴다.
  - `reduceFarm` 에 `{ type: 'use'; items: Partial<Record<CropId, number>> }` 를 추가: 모두 충분할 때만 한꺼번에 빼고, 하나라도 모자라면 아무것도 안 뺀다(테스트 포함).
- **기본 재료**(농장에서 안 나는 것): 우유 🥛, 얼음 🧊, 설탕 🍬, 밀가루 🌾, 달걀 🥚, 초콜릿 🍫, 커피콩 ☕, 탄산수 🫧
  - 냉장고 *식료품 칸*에서 농장 코인으로 산다(1~2코인, 한 번에 3개 묶음). 코인은 농장 `coins` 를 그대로 쓴다(`spend`).
  - 개수는 새 저장소 `src/lib/kitchen.ts` 에 둔다.
- 재료 그림은 `public/kitchen/ing/<id>.webp` 에 넣을 예정. 그림이 없으면 이모지로 보여 준다(`FarmScene` 의 `FarmImg` 처럼 onError → 이모지).

카페 `MENU` (`src/components/CafeGame.tsx`) 를 `src/lib/recipes.ts` 로 옮기고 레시피를 붙인다. 아래는 제안, 숫자는 조정 가능.

| 메뉴 | 재료 | 단계 |
|---|---|---|
| 카페라테 | 커피콩 1, 우유 1 | 갈기 → 붓기 |
| 아이스 커피 | 커피콩 1, 얼음 1 | 갈기 → 붓기 |
| 딸기 우유 쉐이크 | 딸기 2, 우유 1, 얼음 1 | 씻기 → 섞기(믹서) |
| 딸기 에이드 | 딸기 2, 탄산수 1, 얼음 1 | 씻기 → 썰기 → 붓기 |
| 마카롱 | 밀가루 1, 달걀 1, 설탕 1, 딸기 1 | 섞기 → 굽기 |
| 딸기 컵케이크 | 밀가루 1, 달걀 1, 우유 1, 딸기 1 | 섞기 → 굽기 → 올리기 |
| 딸기 케이크 | 밀가루 1, 달걀 1, 우유 1, 딸기 3 | 섞기 → 굽기 → 올리기 |
| 딸기 롤케이크 | 밀가루 1, 달걀 1, 설탕 1, 딸기 2 | 섞기 → 굽기 → 말기 |
| 초코 딸기 | 딸기 3, 초콜릿 1 | 씻기 → 녹이기(냄비) → 찍기 |
| 딸기 젤리 케이크 | 딸기 3, 설탕 1, 우유 1 | 끓이기 → 굳히기(냉장고) |

- 당근·옥수수도 쓰이게 새 메뉴를 더한다: **당근 주스**(당근 2, 얼음 1), **당근 케이크**(당근 2, 밀가루 1, 달걀 1), **옥수수 수프**(옥수수 2, 우유 1), **콘치즈**(옥수수 2, 우유 1 — 치즈 대신). 새 메뉴 그림 `public/cafe/menu2/<id>.webp` 이 생길 때까지는 이모지.
- 메뉴 값은 재료가 많을수록 비싸게(재료값 합 + 2~4코인 이득).

## 4. 흐름

1. **카페에서 주문 받기**: 지금처럼 손님 💬 를 눌러 주문을 받으면 **주문서**가 생긴다(손님 이름·얼굴, 메뉴 그림, 필요한 재료).
   - 지금 카페의 "눌러서 만들기 → 타이머" 단계는 없앤다. 대신 손님 위에 "🍳 주방에서 만들어 주세요" 표시, 카페 화면에 `🍳 주방 가기` 버튼.
2. **주방에서 요리**:
   - 화면 위쪽(또는 조리대 옆)에 **주문서 보드**: 받은 주문서가 카드로 줄지어 붙는다. 하나를 누르면 그 요리를 시작.
   - 필요한 재료 목록이 ✔/✖ 로 보인다. 모자라면 "🥕 농장에서 가져오기"(농장 탭으로) / "🛒 식료품 사기"(냉장고) 버튼.
   - 재료가 다 있으면 재료 아이콘을 눌러(또는 끌어서) 도마로 옮긴다 → 레시피 단계를 하나씩 한다. 단계마다 그 자리(싱크대·냄비·오븐·믹서)로 아바타가 걸어가고, 한 번 누르기 / 여러 번 톡톡 / 길게 누르기 같은 아주 짧은 동작(2~4초)과 효과음·반짝임.
   - 끝나면 완성 그림이 **완성 쟁반**(조리대 오른쪽)에 올라가고 딩동(`playBell`). 재료는 이때 실제로 빠진다.
   - 실패는 없다. 틀린 곳을 누르면 그 단계가 흔들리며 "여기를 눌러요" 힌트만.
3. **카페에서 서빙**: 카페로 오면 완성된 음식이 있는 손님 머리 위에 "완성!" 표시. 손님을 누르면 아바타가 음식을 들고 가서 서빙 → 코인·행복 카운트·단골 보너스는 지금 카페 로직 그대로.

## 5. 상태와 저장

- `src/lib/kitchen.ts` (순수 함수 + 저장, `farm.ts` 와 같은 패턴: `defaultKitchen`, `sanitizeKitchen`, `reduceKitchen`, `getKitchen`, `subscribeKitchen`, `actKitchen`, 키 `ryuso.kitchen.v1`, `isRestoring` 존중)
  - `pantry: Record<기본재료, number>`
  - `tickets: { id, seat, menu, status: 'waiting' | 'cooking' | 'ready', step }[]` — 카페 손님과 주방이 같은 주문서를 본다
  - 액션: `addTicket`(카페에서 주문 받을 때), `start`, `step`, `finish`(재료 빼기: 농장 `use` + 식료품), `serve`(카페에서 서빙하면 지움), `buy`(식료품)
- 카페의 `kept` 손님 상태와 주문서가 어긋나지 않게: 손님 `stage` 를 `'new' | 'ordered' | 'ready'` 로 바꾸고, 주문서 상태에서 계산한다.
- 백업(`src/lib/backup.ts`)에 주방 저장도 넣는다.

## 6. 화면·소리

- 세로(폰)·가로(패드·폰 가로) 모두 확인. 가로 폰처럼 낮은 화면에서 주문서 보드와 버튼이 그림을 덮지 않게.
- 앱 전체에 `button { font: inherit }` 가 있어서 버튼 글자 크기·굵기는 `style` 이나 안쪽 `span` 에 준다.
- 소리: 주문서 생김 `playOrder`, 단계 `playCook`/`playTap`, 완성 `playBell`, 서빙 `playServe`. 배경 음악은 카페 노래(`startBgm('cafe')`)를 같이 쓴다.
- 새 그림 폴더(`public/kitchen/**`)가 PWA 캐시(Workbox)에 들어가는지 `vite.config.ts` 확인.
- 한국어가 기본, 영어 문구도 같이(`useI18n`).

## 7. 건드리지 말 것

- 농장 심기·물주기·수확·밭 사기, 카페 전화(📱·동물 통화), 다른 탭은 그대로.
- 카페 손님 자리·그림·배경 음악·단골 보너스 로직은 유지(만들기 단계만 주방으로 옮김).

## 8. 확인

- `tsc -b`, `vitest` 전부 통과. 새 테스트: 레시피 재료 id 가 모두 실재, 농장 `use` 가 모자라면 안 빠짐, 주문서 → 완성 → 서빙 흐름, 저장 sanitize.
- 헤드리스 Chromium(`/opt/pw-browsers/chromium`, `npx vite preview`)으로 세로 390×844, 가로 844×390, 패드 1180×820 스크린샷:
  카페 주문 → 주방 요리(재료 모자람 → 농장 재료 넣고 다시) → 완성 → 카페 서빙까지.
- 실제 폰/태블릿에서 해 보지 않았다면 그렇다고 분명히 말하기. 소리를 못 들었으면 그것도.
- 새 브랜치에서 작업하고 PR 을 만든다.
